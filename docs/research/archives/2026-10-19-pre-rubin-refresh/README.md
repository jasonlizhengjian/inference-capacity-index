# Supporting analyses before the Rubin refresh

This archive preserves the sensitivity results using 15 October hardware profiles
and the validation using 19 October observations before its 29 October refresh.
Rubin uses 22 TB/s HBM and 1.8 TB/s outbound NVLink in these archived calculations.

[Original outputs and calculation scripts](supporting-analyses.zip) | [File hashes and source commit](manifest.json).
The archive contains previously published repository files only.
For the refreshed results, see [sensitivity](../../methodology-sensitivity/README.md)
and [validation](../../inferencex-validation/README.md).

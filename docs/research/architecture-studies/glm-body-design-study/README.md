# GLM-style depth, width and MoE

87 model definitions varying total/active routed parameters, depth, expert granularity and shared experts with GLM-style DSA.

- [Saved report](output/GLM_BODY_DESIGN_STUDY.html)
- [Tables and model/hardware inputs](data.zip): unzip in this directory to restore `output/*.csv`, `models/` and `systems/` where supplied.
- [Archived source wrappers](source/)
- [Archive scope, engine versions and limitations](../README.md#scope-and-reproduction)

These are historical conditional projections, not current ICI scores or evidence of equal model quality. The reports retain their original hardware and acceptance assumptions. No timing or configuration search was rerun for this archive.

Source wrappers are provided for inspection. They still depend on their original research directory layout, historical runtime and sibling studies; they are not a standalone reproduction command. Literal workspace paths have been replaced by named placeholders. See the collection manifest for original and published file hashes.
